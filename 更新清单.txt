使用方式
=============================================================================

方式1: 基础提取（不需要LLM）
  命令: python -m src.main "URL"
  输出: JSON + Markdown + Banner图片信息(如果有)

方式2: 完整工作流（需要配置LLM）
  命令: python run_with_llm.py "URL"
  输出: JSON + Markdown + 两个Banner + 一页纸HTML + 翻译

方式3: 编程方式
  from src.workflow import ArticleWorkflow
  workflow = ArticleWorkflow()
  result = workflow.process(url, ...)

3. 配置LLM（如果需要完整工作流）:

   - 配置API密钥

   python run_with_llm.py "https://example.com/article"

5. 查看生成的文件:
   ls -R output/

=============================================================================
已知限制和注意事项
=============================================================================

1. 图片Banner只保存URL信息，不下载图片到本地
2. 完整工作流需要配置LLM API
3. 图片尺寸检测需要网络请求（增加2-5秒处理时间）
4. 一页纸HTML默认使用SVG Banner（可修改为图片Banner）

技术支持
=============================================================================

问题排查:
  - 查看日志输出了解详细错误
  - 检查 output/ 目录是否有生成文件
  - 确认依赖是否正确安装

常见问题:
  - 未找到大尺寸图片 → 正常，使用SVG Banner即可
  - LLM调用失败 → 检查API配置和网络连接
  - 图片尺寸检测超时 → 网络问题，会自动跳过继续处理
