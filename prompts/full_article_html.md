# 生成完整文章 HTML（宿主 agent 执行）

输入：元数据 + 正文内容 + 媒体资源（来自 `output/extract_*.md` / `*.json`）。

提示词要点：
- 现代、简洁、专业的设计风格（Medium 或现代技术博客）
- 保留所有原文内容，不删减任何信息
- 在适当位置嵌入图片（使用提供的图片 URL）
- 响应式设计，适配移动端
- 包含标题、作者、日期等元数据
- 代码块使用等宽字体和语法高亮样式
- 使用中文界面（如「作者」「发布时间」等标签）

输出规范：
- 只输出完整 HTML 代码，第一行即 `<!DOCTYPE html>`
- 严禁在代码前后添加 ```html 或 ``` 标记
- 若已翻译则输出中文正文
