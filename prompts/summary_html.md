# 生成一页纸解读 HTML（宿主 agent 执行）

任务：将正文提炼成极其美观、现代、高可读性的单页 HTML，长度控制在 1-3 屏/页。

结构要求：
- 顶部预留 16:9 banner 容器，使用如下结构并保留占位标记 `<!--BANNER_SLOT-->`：
  ```html
  <div class="banner"><!--BANNER_SLOT--></div>
  ```
- 开头：1 个【一句话总结】+ 2-3 个核心亮点卡片
- 模块化结构：背景/原理、核心架构、关键步骤/API、常见问题与最佳实践
- 多用对比表、高亮卡片（Callout）、列表，拒绝大段落
- 代码块带语法高亮结构与语言标签，关键参数行内高亮
- 只基于原文，不编造原文没有的数据
- 结尾用简短小节总结「这意味着什么」
- 标题区含标题、作者、日期、原文链接

视觉规范（内联 `<style>`）：
- 配色：背景 #F8FAFC，卡片 #FFFFFF，主色 #2563EB，深字 #1E293B，次字 #64748B，边框 #E2E8F0
- 系统级无衬线字体，行高 1.6
- 卡片式布局：圆角 12px，微阴影 `0 4px 6px -1px rgba(0,0,0,0.05)`
- Callout/Badge/对比表组件
- 最大宽度 900px 居中，响应式

输出规范：
- 直接输出完整 HTML（含 <!DOCTYPE html>、<style>、<body>），CSS 全内联，不引外部资源
- 严禁 ```html 标记；必须原样保留 `<!--BANNER_SLOT-->`
