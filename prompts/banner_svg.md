# 生成 16:9 Banner SVG（宿主 agent 执行）

输入：标题、副标题（可由提炼得到）+ 一张意象描述。

目标：极简手绘编辑插画 Banner，Anthropic 风格。

对于主标题、副标题与意象：
- 从元数据标题提炼主标题（8-15 字）
- 提炼一句意象画面（15-30 字），例如「一组手绘齿轮与代码符号围绕一个中心节点」

SVG 构图约束：
- viewBox="0 0 1600 900"，背景用 <rect> 纯色铺满四角
- 背景色从浅色板随机选一：`#CBCADB #BCD1CA #E3DACC #C4C4D8 #CBD7E3 #D8D0C4 #D9E3C8 #E0CCD6`
- 只用三色：满版背景色 + 象牙白承载形状 `#FAF9F5` + 线条/文字 `#141413`（背景必须为指定色值）
- 左侧 x<690 为纯文字区，禁止放任何图形
- 右侧 x>760 放不规则、轻微手绘感的象牙白大形状，占右侧约 55%-70%
- 象牙白形状上用粗重圆润黑色线条（stroke-width 8-16，round）画单一意象主体，不加装饰点缀
- 标题/副标题之外不得出现任何多余文字（无 Logo、日期、网址）
- 不使用渐变、阴影、3D、图片嵌入、外链、外部字体、透明背景

排版：
- 主标题/副标题用大字号、左侧留白，分隔清楚
- 可用按宽度换行（中文按字宽≈字号估算）

输出规范：
- 直接输出完整、可运行的 SVG 代码，不要 ```svg 标记或解释文字
